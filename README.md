# Keisung App · 계성 스마트

학교 생활 통합 웹앱(PWA) 개발 저장소입니다.

- **학교 생활 홈**: 급식, 학사 일정, 우산 대여 연결
- **급식·학사일정**: 나이스 교육정보 개방 포털 공식 OpenAPI 사용 예정
- **우산 대여**: 별도 저장소 [keisung-umbrella](https://github.com/Lee-sangyul/keisung-umbrella)를 유지하며 HTTPS URL로 연동
- **학생증**: 학교의 공식 인증·승인 체계 구축 전까지 발급 및 유효 QR 제공 안 함
- **알림**: 사용 동의 및 인증 인프라 구축 후 추가

> 이 저장소는 개발 프로젝트이며, 학교의 공식 앱 또는 학생증임을 의미하지 않습니다. 실제 교내 사용에는 학교의 사전 승인이 필요합니다.
